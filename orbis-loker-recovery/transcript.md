# Loker — Product Requirements Document (PRD)

**Version:** 0.1 (working prototype) · **Status:** Prototype built & verified · **Owner:** TBD

## 1. Summary
Loker is a **chat-first job platform for Indonesia**. Job seekers message the **employer/boss directly** (no HR, no `calo`/brokers), guided by an **AI match score**, with an anti-scam **"Verified Employer"** badge as the core trust promise.

**One-liner:** *"Chat langsung dengan bosnya — tanpa perantara, tanpa penipuan."* / *"Chat directly with the boss — no middlemen, no scams."*

## 2. Problem
- Indonesian job boards (JobStreet, Kalibrr, Glints) skew **white-collar** and are **resume-upload / one-way** — applications vanish into a void.
- **Blue-collar / first-job seekers** (the majority) are underserved.
- **Scams and fake listings** are a major, widely felt pain point.
- No direct line to the **decision-maker**; HR acts as a slow middleman.

## 3. Target Users (personas)
| Persona | Description | Need |
|---|---|---|
| **Andi** (primary) | 18–30, blue-collar / first job, mobile-first, low data budget | Find a legit job fast, talk to a real boss, avoid scams |
| **Bu Sari** (employer) | SME owner (F&B, retail, logistics) | Hire quickly without HR or expensive consultants |

## 4. Value Proposition / Differentiation
1. **Direct chat with the boss** (removes HR middleman).
2. **Verified Employer badge** — anti-scam trust (the wedge).
3. **AI match score** — recommendation feed, not search.
4. **Mobile-first + offline-capable** — works on cheap phones / poor connectivity.
5. **Bilingual** — English ⇄ Bahasa Indonesia.
