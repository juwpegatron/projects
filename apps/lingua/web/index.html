Always-on-top overlay

Lingua

Teams talks. You read along, translated.

How it works

  • Screen-read, not hooked — Teams has no public caption API, so Lingua grabs the pixels of the region where Teams draws captions (crop downscaled to 640 px for speed).
  • Change detection — a perceptual hash skips OCR + translate when the caption strip is unchanged, so idle time costs nothing.
  • Two-stage pipeline — OCR, then translate, on a background worker; the UI never blocks.
  • Running transcript — a single always-on-top window holds the controls and the live, auto-scrolling transcript.
  • Light / dark theme, selectable source/target languages, opacity, font size and click-through.

Run it

  • python app.py (or scripts\run.ps1)
  • Gateway endpoints + models are configured via environment variables — see the README.
